# 네이버 ETF 분석

네이버 금융 데이터를 활용해 ETF의 기본 정보와 수익률을 간단히 분석하는 프로젝트입니다.

## 분석 내용

- ETF 종목 및 기본 정보 확인
- 기간별 가격과 수익률 비교
- 거래량과 변동성 확인
- 관심 ETF 간 성과 비교

## 기본 흐름

1. 네이버 금융에서 ETF 데이터를 수집합니다.
2. 결측치와 날짜 형식을 정리합니다.
3. 수익률, 변동성 등 주요 지표를 계산합니다.
4. 표와 그래프로 분석 결과를 확인합니다.

## 참고

본 프로젝트의 분석 결과는 학습과 참고를 위한 자료이며, 투자 판단의 근거로 사용해서는 안 됩니다.
